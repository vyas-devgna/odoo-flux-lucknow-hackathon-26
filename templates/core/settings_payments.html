How to enable it

  1. Create a Razorpay account and use test mode keys first.
  2. Set RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET and RAZORPAY_WEBHOOK_SECRET in the server environment, then restart.
  3. In the Razorpay dashboard add the webhook URL for payment_link.paid and payment.failed.
  4. Open an invoice and create a payment link. Test payments are marked test and excluded from cash reports.

Without keys, customers report bank or UPI payments from their invoice; staff confirm them against the statement.
